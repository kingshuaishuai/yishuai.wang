# 博客开发与验收

## 实施边界

已确认的视觉设计迁移到独立 Nuxt 应用。一个 D1/SQLite 数据库保存业务数据，R2 保存图片；不引入 ORM、独立缓存或搜索服务。文章与短记共用内容表，草稿与公开快照分开，保存草稿不改变公开内容。

## 当前实现

- Nuxt SSR 真实路由与正文，canonical、文章结构化数据、sitemap、RSS、Markdown、llms.txt。公开列表只投影标题与摘要，不携带完整正文或私有草稿。
- GitHub OAuth + PKCE，作者按固定用户 ID 识别。会话可撤销，浏览器写入检查 Origin 和 CSRF；访客和普通登录用户无写作权限。
- 登录读者有只管理自己头像的个人中心；支持 PNG/JPEG/WebP（原图最大 5 MB），通过 QuireKit FileUpload 与 ImageCropper 弹窗裁剪，输出最大 512×512 的 WebP。服务器检查会话、CSRF、文件头和 1 MB 上限，不接受客户端指定账户。替换后旧头像地址失效，现有评论使用账户当前头像。
- 内容与评论管理按页读取，可访问较早记录；列表不传输完整草稿。作者导航统一为「创作管理」，桌面放在右上角路由导航，手机放在同一导航菜单；页脚不再重复作者入口。
- 草稿保存、预览、发布、撤回、软删除/恢复和版本冲突保护。本机副本需作者明确恢复，不自动覆盖服务端。站内返回提供「继续编辑／保存并离开」，浏览器关闭也提醒未保存修改。
- 管理列表标题区域可进入编辑，内容类型与发布状态使用日期同行的小号中性 QuireKit Tag；全站使用 Ink 明暗主题。页面最小高度为可见视口，短页面页脚在底部，长页面随内容流动；写作页也由正文撑开布局，状态栏到达页面底部。带图标按钮使用公共 leading/trailing 插槽。
- 写作的文档、实时预览、源码通过 md-editor 的 view 属性切换，保持编辑实例及完整工具栏、左侧块控件。阅读使用公共 MdProse 和同一份 EditorState，并注入代码展示组件；标题通过公共 header 插槽与正文对齐。当前 MdEditor 的内置阅读视图尚未提供 components 注入入口。
- 封面与描述选填；无图不预留占位，描述留空时从正文提取。封面保存在内容 JSON 快照中，不增加专用表；公开列表、正文、OG、结构化数据、RSS、Markdown 使用同一公开封面。Micropub 支持 IndieWeb 的 featured 扩展属性。
- 写作顶部将内容类型、编辑视图和保存发布并排，窄屏将视图选择换到下一行。描述为自动增高的多行输入；分类为 Select，标签在弹窗中多选，确认后更新。选项接口仅作者可访问，从当前草稿和公开快照中汇总，不向列表传输正文；不再要求手输分类和逗号标签。
- 首页提供 GitHub（QuireKit 组织）和 X（@quirekit）链接。山景随居中正文定位，宽屏左侧补充淡远山，窄屏隐藏侧景。
- MSFE 评论与回复直接显示，使用 md-editor 的公开扩展与视图接口提供文档、实时预览和源码。模式切换保持同一编辑实例、选区与撤销记录；输入区等高，长内容内部滚动，异步加载预留同等空间。匿名或登录身份、待审核/公开/隐藏状态；邮箱和未审核内容不公开。
- 编辑和阅读复用 md-editor 语言目录与 Lezer 语义标记，明暗配色分别定义。SSR 和语言包使用同一 Lezer 运行时，避免节点属性冲突；未知语言或超过 50,000 字符的代码保留纯文本。复制使用原始代码，着色以 Vue 文本节点输出。
- 生产预览从独立构建快照启动，构建期间保持原服务可用；使用绝对环境文件和本地数据路径，重复启动不会替换正在运行的快照。
- R2 图片检查文件头和大小，最大 8 MB。上传后默认仅作者可见，公开内容引用后开放，撤回后停止公开读取。
- 图片公开性只判断当前发布的正文、原始内容和封面字段，不能由保留的扩展元数据单独开放。封面上传期间禁用保存和发布，避免保存未完成的图片引用。
- Micropub create/source/config/update/delete/undelete/media、表单和 JSON、浏览器跨域。原始 HTML/文本和扩展属性保留；不支持的 private/unlisted/scheduled 状态明确拒绝，避免误公开。

## 验证结果

- Nuxt 类型检查、29 项测试与 Worker 生产构建通过。测试覆盖发布快照、版本冲突、撤回同步、评论幂等与隐私、会话/CSRF、头像替换与并发冲突、封面可见性、分类标签权限、Micropub HTTP 生命周期及多语言着色的原文保真。
- 内置浏览器完成真实 GitHub 回调和作者识别、草稿保存后重新载入、发布、MSFE 评论提交/审核/隐藏、文章撤回。保留作者的头像、草稿，以及作者后来修改的封面和代码；临时评论文字未提交并已清空。
- Worker 本地预览通过无 JavaScript 的文章正文与代码语法标记、元信息、RSS、Markdown、llms、404、访客拒绝与 CORS 检查。正式构建里直接打开作者写作链接正常。
- 实测文档工具栏、块菜单、四种视图切换、站内返回提醒、MSFE 评论实时粗体和行内代码。阅读标题、正文标题与代码块左边缘一致；编辑和阅读代码在明暗主题下均有语义着色。
- 评论区点击前后及三种视图的外框高度均为 282px，输入区为 176px。内置浏览器验证格式与代码高亮、跨视图撤销、刷新恢复、方向键切换；320 / 390px 无横向溢出，深色主题可读。验收文字已清空，未提交评论。
- 320 / 390px 检查写作操作栏与阅读视图，无页面横向溢出；1920px 检查山景与居中正文的关系。全程一倍大小，生产页面深浅主题在刷新后保持一致。原型阶段的其他页面和主题记录保留在原设计验收中。
- 正式 Worker 已发布并绑定 yishuai.wang。公共 DNS 已指向 Cloudflare，保留证书验证的 HTTPS、公开 SSR、canonical、robots、sitemap、RSS、llms.txt、登录配置、私有路由保护和 404 检查通过；本次通过公共解析地址验收，本机解析缓存尚未更新。
- Workers Free 下三次公开页面请求的 CPU 为 27、117、112ms，均返回 200，且无执行异常；该小样本超过免费版每次 10ms 配额，不能代表稳定性或性能验收通过。需完成静态化或渲染优化并复测，当前仍运行于免费版。
