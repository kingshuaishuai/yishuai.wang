# 内容永久删除

## 使用规则

- 创作管理为文章、短记、草稿及以前软删除的内容提供「永久删除」，不再提供「恢复」。作者逐项确认标题及不可恢复说明后删除，不自动清理已有数据。
- 已发布内容仍可「撤回」，保留草稿供以后编辑和发布。
- 删除同时移除该条内容的草稿、公开快照、评论及回复、智能总结。公开详情、Markdown 返回 404，公开列表、RSS、sitemap、llms.txt 不再包含此条内容。
- 其他语言版本独立保留；可以从保留的版本重新创建缺失的语言版本。旧软删除的语言版本需先永久删除，释放对应语言位置。
- 上传图片可能被其他内容或语言版本复用，因此只解除归属，不删除媒体记录与 R2 文件。匿名图片读取仍要求当前公开内容引用；无公开引用的图片仅作者可读。
- 历史访问汇总保留，内容排行不再列出已永久删除的文章。

## 接口与一致性

`DELETE /api/owner/posts/:id` 接收 `{ version }`，要求作者会话、同源 Origin 和 CSRF。成功返回 204，内容不存在返回 404，版本变化返回 409。

关联清理及主记录删除在同一个 D1 batch 事务中执行。每条语句都检查同一 ID 与版本，冲突时不修改任何数据；数据库失败时整体回滚。删除后旧编辑器不能再次保存，正在运行的总结任务不能重新写入已删除的记录。

管理页旧的 `POST .../action` 只接受发布与撤回，不把旧页面中的可恢复确认悄悄变成永久操作。Micropub 保持已有 `delete/undelete` 协议兼容；已永久删除的内容无法通过 `undelete` 恢复。

## 交互

确认弹窗使用 QuireKit Dialog 的 `alertdialog`、任务错误和忙碌状态。初始焦点在取消按钮；提交期间阻止重复操作和关闭。冲突后保持原确认快照、刷新列表并要求重新确认，不自动替换版本重试。

成功后刷新内容和评论分页，末页清空时返回有效页；同时删除当前浏览器对应的本机草稿副本。关闭后焦点返回原按钮，记录已移除时返回内容列表标题。

## 验证

- 隔离 D1/R2 和真实 HTTP 测试覆盖永久删除、草稿及旧软删除记录、版本冲突、关联数据与共享图片、语言版本重建、事务回滚、作者权限、Origin/CSRF、请求校验及旧操作拒绝。
- 全部 61 项测试、Nuxt 类型检查与 Worker 生产构建通过。
- 内置浏览器验证中文桌面和 320px 英文深色弹窗、取消与 Escape、默认焦点及关闭后的焦点返回；窄屏无横向溢出。未删除现有作者内容。
