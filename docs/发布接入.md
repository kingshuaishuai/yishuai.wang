# 发布接入

## 使用

作者登录后，从右上角「发布接入」打开弹窗；窄屏入口在导航菜单中。复制站点地址与 Micropub 接口，为 QuirePub 或其他可信客户端生成独立令牌。

正式站接口为 `https://yishuai.wang/api/micropub`。将它与令牌填入客户端即可，不需要配置外部 IndieAuth 服务。图片端点通过 `GET /api/micropub?q=config` 的 `media-endpoint` 发现。首页继续通过 HTTP `Link` 提供 `rel="micropub"`。

令牌具有 `create update delete undelete media` 权限，只用于发布内容及上传媒体。草稿通过 `post-status: draft` 创建；公开文章仍遵循现有发布快照、语言和永久链接规则。

## 令牌规则

- 仅站点作者可以查看、生成或撤销；普通登录读者不显示入口，服务端也拒绝其管理请求。
- 完整令牌只在生成响应和当前弹窗中出现一次，不写入浏览器持久存储。关闭后只显示名称、尾号、有效期和最近使用时间。
- 数据库只保存 SHA-256 摘要。有效期可选 30 天、90 天或 1 年，默认 1 年；最多同时保留 10 个有效令牌。
- 撤销立即影响后续请求；过期、已撤销及作者身份已变化的令牌均拒绝。最近使用时间最多每五分钟写入一次。
- 管理写入要求同源与 CSRF 校验。令牌响应禁止缓存，创建受频率与数量限制。
- 本站令牌使用独立前缀，验证失败也不转发到外部服务。外部 IndieAuth introspection 仍可选配，禁止携带令牌跟随重定向。

这提供的是客户端手动填写令牌的接入方式，没有实现本站自己的完整 IndieAuth 授权服务器。丢失令牌时撤销旧令牌并重新生成。

## 验证

HTTP 测试使用隔离 D1/R2，覆盖作者权限、Origin/CSRF、只返回一次凭据、摘要存储、配置发现、媒体上传、草稿创建与更新、删除与恢复、撤销、过期、权限校验和并发数量限制。未配置外部 introspection 时，本站令牌仍可使用；真实 Workers 测试覆盖外部校验请求及重定向拒绝。

内置浏览器已验证中英文、浅深色、320/390 像素窄屏、地址复制、有效期选择与关闭后焦点返回。正式站作者弹窗、访客拒绝与只读验收通过；真实 QuirePub 客户端发布互通待配置后验证。
