# 友链管理

## 页面与展示

- 公开页为 `/friends` 和 `/en/friends`，从主导航和页脚进入；均以 SSR 输出可读内容，并纳入 sitemap、语言关联、`llms.txt` 和公开页面访问统计。
- 使用 QuireKit 的 Ink 主题、头像、图标与淡梅枝装饰。桌面两列、手机一列；整张卡片可打开站点，外链使用 `noopener noreferrer`。
- 页头采用紧凑间距，简介自然换行，使首屏优先展示友链卡片；卡片使用紧凑内边距及内容间距，保留正常字号与可读性。整页保持至少一屏，页脚位于底部。
- 卡片展示站点名称、域名、简介和可选图标；英文页优先使用英文简介，未填写时沿用原简介。图标缺失或加载失败时回退为名称首字。
- 友链按阅读兴趣收录，不以交换链接为条件。首个收录站点为 [Ashes Space](https://blog.ashesborn.cloud/)，介绍其 TypeScript GraphRAG、检索与索引工程内容；不公开往来邮件。
- 列表上方提供无需登录的「申请友链」入口，收件邮箱经作者确认使用 `kwyishuai@163.com`。点击直接打开邮件软件并预填站点名称、链接、简介和可选图标模板，访客自行发送；旁边提供 QuireKit 复制邮箱按钮，悬停可查看地址。不新增站内申请表或审核队列，申请入口不随友链数量增加移到页尾。
- 收件地址可用 `NUXT_PUBLIC_FRIEND_REQUEST_EMAIL` 覆盖，中英文页面使用对应语言的邮件标题与模板。

## 管理与数据

- 作者从「创作管理 → 友链管理」进入 `/manage/friends`；英文路径为 `/en/manage/friends`。普通登录读者和访客不可管理，管理页不索引、不缓存。
- 新增和编辑使用 QuireKit 弹窗，支持中英文多行简介、可选图标、排序数字和公开开关。数字小的在前，同值按创建时间和 ID 稳定排序。
- 隐藏只影响公开展示，可以随时恢复；删除前明确确认站点与后果。弹窗打开时聚焦名称，关闭后返回触发按钮，失败保留输入，提交中禁止重复操作。
- D1 迁移为 `0008_friend_links.sql`。公开 API 仅返回可见站点的展示字段；管理字段和隐藏站点不进入公开响应。
- 所有写操作要求作者会话、同源请求和 CSRF 校验。URL 只允许无凭据的公开 HTTPS 地址，名称与简介限制长度；服务端不抓取外部元数据。归一化 URL 的唯一约束防止重复添加。
- 编辑、隐藏和删除携带版本号，以数据库条件写入防止旧页面覆盖新修改。冲突后刷新列表，重新打开最新版本再操作。
