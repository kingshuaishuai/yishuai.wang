# 智能总结

## 当前规则

- 使用 DeepSeek Chat Completions 的 SSE 接口完成一次摘要生成，不引入 Agent、工具调用或检索流程。默认使用 `deepseek-flash` 的非思考模式。
- 模型 ID 由作者自行填写，常用型号仅作为快速填写项；更换模型名称不需要重新部署。模型必须兼容 DeepSeek Chat Completions 的文本流接口。
- 只有作者可配置模型与 Key。Key 经独立服务端密钥加密后存入 D1，读取接口只返回是否已配置；浏览器、日志和公开响应不得收到已有 Key。
- 开启后，网页与 Micropub 发布文章都会触发后台生成。只发送已发布的标题、正文和语言，不发送草稿、评论、身份或密钥以外的配置。
- 每个语言版本独立生成。摘要与正文摘要字段分开保存，不改变原文、SEO 描述、文章地址和发布时间。
- 结果按照正文指纹缓存，访客访问不会调用模型。正文变化后旧总结不再展示；并发任务和过期结果不能覆盖新版本。失败不阻断发布，作者可以重试。
- 手动重新生成时通过站内 SSE 展示进度，完整成功后才替换公开总结。超时、截断或中断的部分结果不公开。
- 文章标题下展示机器人图标、「智能总结」和摘要，沿用 Ink 配色。未生成时不出现占位卡片或加载跳动。

## 运行边界

- 服务端 `NUXT_AI_SETTINGS_SECRET` 为独立的 32 字节十六进制密钥，保存于 Worker secret；备份恢复时必须保留，不提交仓库。
- 请求固定发往 DeepSeek 官方 HTTPS 接口，不跟随重定向。正文最多 60,000 字符，生成请求最多等待 24 秒，超限明确标记失败。
- 后台任务使用 Cloudflare `waitUntil`；任务中断后租约过期即可重试，不依赖访客流量重试。管理页提供配置入口，写作侧栏显示生成状态。
- 开启设置只影响后续发布；既有文章由作者点击生成，避免设置保存时批量调用模型。
