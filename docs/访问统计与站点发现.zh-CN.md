# 访问统计与站点发现

## 站点发现

- `/sitemap.xml` 提供中英文公开页面和已发布内容的永久地址；`robots.txt` 声明该地址。管理、账号、统计、草稿、已撤回和已删除内容不进入 sitemap。
- 只读取公开快照的元数据，不渲染文章正文。`lastmod` 使用公开版本更新时间，保存私有草稿不会改变它；语言关联只包含真实已发布的版本。
- 响应提供 XML 类型与 ETag，每次重新验证。未变化返回 304，发布或撤回后立即反映当前列表。`llms.txt` 复用同一元数据投影。
- Sitemap、robots、llms.txt 和四个语言/内容 RSS 入口均响应 GET 与 HEAD；HEAD 返回同样的资源状态和头信息，不返回正文。
- Sitemap 是发现入口，不代表搜索引擎已收录；可在 Search Console 提交 `https://yishuai.wang/sitemap.xml` 并查看抓取状态。

## 统计口径

- 复用 D1，迁移为 `0007_analytics.sql`；无需额外服务或分析平台账号。
- 客户端在公开页面连续可见 5 秒后上报一次。作者登录后的访问、已识别的爬虫、私有或不存在的地址，以及 DNT / GPC 请求不计入。统计失败不阻止阅读。
- 同一浏览器、同一页面在每个固定半小时窗口内只计一次。窗口交界处可能各计一次；浏览次数不是完整阅读次数，也不是精确人数。
- 日期按 Asia/Shanghai 划分。浏览器每天生成新的匿名随机标识，服务端加盐并按天散列后去重。日访客跨设备、清除存储后可能重复；面板的「日访客合计」是各日数字相加，不是整个区间的去重人数。
- 不保存原始 IP、完整来源网址或搜索参数。来源按当前页面会话入口域名归属；RSS 阅读器内的阅读不计入。清理工作随后续请求触发，每次最多移除 100 条过期事件和 100 条访客记录，保留当日及此前两日的去重数据；无后续请求时不会承诺定时删除。长期保留按天、页面和来源域名的汇总。
- 写入使用 D1 事务批次和事件唯一约束。只有本次接受的新事件才能更新汇总，避免并发重复计数；请求限定同源、大小和频率。客户端信号可被伪造或屏蔽，因此这些数据用于观察趋势，不用于计费或审计。

## 页面与权限

- 作者从「创作管理 → 访问统计」进入 `/analytics`，英文为 `/en/analytics`。提供 7 / 30 天范围、浏览趋势、每日数据、热门文章和来源域名。
- 统计页面与接口仅作者可读，页面禁止索引与缓存。访客不能获取面板数据、匿名标识或私有配置。
- 文章标题下默认显示累计浏览次数，与阅读时长并列。面板开关可隐藏公开数字，私有汇总继续记录；普通读者只获取当前公开文章的总数。
- 数据从功能启用时开始，不估算历史访问；本地验收数据不迁入生产。

## 验证

- `pnpm check` 的类型检查、52 项测试及 Worker 构建通过。
- 真实 D1 模拟器与 HTTP 测试覆盖并发去重、每日访客、跨窗口计数、作者排除、隐私请求、同源/CSRF/权限、限流、公开开关和过期去重数据清理。
- 站点发现测试覆盖发布快照隔离、双语关联、撤回/删除、ETag 及 304；生产只读验收检查 XML 类型、绝对地址、无重复 URL、私有页面排除及条件请求。
- 内置浏览器验证面板范围选择、每日表格、公开开关、文章次数和作者访问排除；320 / 390px 中英文与明暗主题均保持一倍大小，无横向溢出。
- 正式 D1 已应用至第七项迁移；迁移前已保留私有数据库导出。正式站的作者面板可切换范围，已接收到公开页面的访问信号，文章标题下的次数可见；本地模拟流量未写入生产。
- 正式 sitemap XML 解析通过，包含 14 个不重复的公开地址；GET / HEAD 为 200，ETag 条件请求为 304。Workers 日志确认 sitemap 和统计请求正常完成。全量生产巡检仍受本机间歇性连接超时影响，尚未一次完整跑通。

参考：[Google sitemap 指南](https://developers.google.com/search/docs/crawling-indexing/sitemaps/build-sitemap)、[D1 批量事务](https://developers.cloudflare.com/d1/worker-api/d1-database/#batch)。
