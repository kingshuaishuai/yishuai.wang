# 多语言内容与阅读导航

## 当前规则

- 中文界面保持原地址，英文界面使用 `/en` 前缀。URL 决定界面语言，服务端与客户端保持一致。
- 文章、短记分别保存内容语言。历史内容视为中文；已发布内容不再改变语言或永久地址。
- 同一内容可创建一个中文版本和一个英文版本。两者独立编辑、发布、撤回和评论；创建另一版本不自动翻译或发布。
- 首页与列表默认显示当前界面语言，文章列表可选择中文、English、全部。没有译文时不伪造对应文章。
- 目录位于文章标题旁，使用 QuireKit Anchor 跟随滚动；窄屏使用可展开目录。选区使用清晰的蓝色，整体主题保持 Ink。
- 详情页不显示封面和描述；保留其列表、搜索摘要和分享卡片用途。
- 手机导航使用 QuireKit Popover 浮层，外部点击、Escape 和选项导航后关闭，不改变正文位置。文章语言和分类使用文字式 Select，当前选择直接显示。
- SEO 仅为真实已发布版本输出互相对应的 `hreflang`。RSS 分中文、英文和全部，Markdown 与 llms.txt 标明内容语言。

## 验证

- 32 项测试与类型检查通过，覆盖历史中文默认值、并发创建同一语言版本、草稿不进入公开链接、独立发布与撤回、Micropub 语言往返、RSS、Markdown、sitemap 及永久地址约束。
- 内置浏览器通过中英文创建与独立发布、文章版本跳转、界面切换后的默认筛选、手机目录、明暗高亮和导航浮层；验收内容只在本地创建，结束后已软删除。
- 本地 HTTP 验证中英文 SSR、代码高亮、canonical/hreflang、语言规范路径、订阅源与私有路由保护通过。生产构建和压缩后的部署预检通过。
- 生产已应用语言迁移并部署。中英文页面、RSS、llms.txt、SEO 与访客权限只读验收通过；原文章 URL、正文哈希、标题、封面和更新时间均与部署前一致。线上目录跳转与滚动高亮已在内置浏览器验证。
